  bodyNamesAttestedActor=false. A role noun is not a NAME, so the write
  seam's name gate and the read seam's S3 both had nothing to refuse and the

  noun) and is applied at BOTH seams — `postTitleViolations` (write) and
  `servedPostTitleViolations` (read, which `projectPostTitle` uses), so the

  exempt so the fallback is never re-derived.
